# Bash Tools

A collection of useful command-line tools written in Bash.

## Tools Included

- **MySQL Management (`tools_create_db_mysql.sh`)**: A comprehensive script to create, manage, and delete MySQL databases and users interactively. It includes robust error handling and validation to ensure safe operations.

## Usage

Each tool is self-contained. To use a script, navigate to this directory in your terminal, make the script executable, and then run it.

Example for the MySQL tool:
```bash
chmod +x tools_create_db_mysql.sh
./tools_create_db_mysql.sh
```
